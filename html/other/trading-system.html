维克多趋势交易系统

融合 双突破、123 法则 与 2B 法则 三大经典反转信号，用「环境判定 → 信号共振 → 风险控制 → 趋势离场」四层结构，构建一套纪律化、可复制的趋势反转交易框架。

双突破 · 定环境 123 · 主信号 2B · 增强信号 单笔风险 ≤ 2%

  • 1-2-3 法则：突破趋势线 → 回踩不创新低/高 → 突破反弹点，三步确认反转

  • 趋势判定：顺应大级别趋势，只在关键反转信号出现时出手
  • 风控哲学：耐心等待高胜率信号，严格止损

System Overview

系统核心理念

市场如火山运动：趋势是岩浆的流向，信号是喷发的征兆，风控是地壳的防线。只做大方向明确、信号共振、风险可控的交易，其余时间耐心等待。

1

顺势——双突破定方向

先用「长期趋势线 + 形态颈线」的双突破判定大级别趋势是否反转，只允许在突破方向上开仓，绝不逆势。

2

共振——123 + 2B 入场

以 123 法则为主信号、2B 法则为增强信号，配合放量与背离过滤，信号共振时才扣动扳机，追求高胜率与高盈亏比。

3

守本——纪律化风控

每一笔交易都预设止损与固定风险比例，让亏损可承受、可复制，保护本金如同加固火山口的防线。

信号一 · 定环境

双突破（Double Breakout）

在长期下跌末端，价格同时向上突破两条关键压力：长期下降趋势线 与 底部形态颈线（双底 / 头肩底 / 圆弧底等）。

  • 条件 A：收盘价站上长期下降趋势线
  • 条件 B：收盘价突破底部形态颈线
  • 确认：突破伴随放量，信号可信度显著提升
  • 结论：双突破成立 → 大级别由空转多，此后只做多

空头方向镜像同理：长期上升趋势线 + 顶部形态颈线同时被跌破 → 转空。

信号二 · 主入场

123 法则（主信号）

反转三部曲，结构清晰、可量化，是整套系统的主力入场依据。

  • 点 1：价格向上突破下降趋势线
  • 点 2：回踩不再创新低，形成更高低点（Higher Low）
  • 点 3：价格升破点 2 反弹高点 → 买入信号确认
  • 止损：置于点 2 低点下方（留出缓冲）

空头镜像：跌破上升趋势线 → 反弹不创新高（Lower High）→ 跌破反弹低点，即为做空信号。

信号三 · 增强入场

2B 法则（增强信号）

专抓「假突破陷阱」，比 123 更早、入场点更优，用于提前进场或与 123 共振加成。

  • 下跌趋势中价格创新低，但快速拉回站上前低 → 空头陷阱，看多
  • 与 123 同时出现时，共振信号胜率最高，是系统最佳入场形态
  • 止损：置于假突破低点下方
  • 空头镜像：创新高后迅速跌回前高之下 → 多头陷阱，看空

注意：2B 属逆势抄底摸顶，胜率偏低、盈亏比高，必须严格止损。

Position Adding

利用持续形态加仓

底仓建立后，趋势不会直线运行，中途的整理（持续形态）正是顺势加码、放大利润的最佳时机。本章提供两种加仓方式：方式一顺势突破加仓（稳健），方式二假跌破加仓（2B 法则，更早更优）。

加仓方式一 · 顺势突破

突破持续形态加仓

底仓由反转信号建立后，趋势中途的持续形态整理，顺势向上突破是最稳健的加仓信号。

  • 识别形态：旗形、三角旗、三角形、矩形、楔形
  • 加仓触发：价格放量突破形态上边界（多头）
  • 止损设置：跌破形态下边界 / 形态内低点，跌回形态内即离场
  • 仓位约束：单次加仓风险 ≤ 2%，总仓位风险 ≤ 20%

空头镜像：跌破持续形态下边界加空，价格反弹回形态内即止损。

加仓方式二 · 假跌破陷阱

假跌破加仓（2B 法则）

持续形态整理末端，价格假跌破形态下边界（诱空）后快速拉回——这是 2B 法则在持续形态中的运用，入场更早、点位更优。

  • 识别信号：价格跌破形态下边界，但快速拉回站回形态内（空头陷阱）
  • 加仓触发：拉回站回形态下边界上方即可加仓，无需等突破
  • 止损设置：置于假跌破低点下方
  • 组合用法：可先 2B 轻仓加、突破上边界再加码，与方式一叠加

空头镜像：价格假突破形态上边界（诱多）后快速回落，即 2B 加空信号。

1

识别持续形态

旗形（Flag）、三角旗（Pennant）；三角形：对称 / 上升 / 下降；矩形箱体、楔形。本质是趋势中的健康回调，整理后大概率延续原趋势。

2

加仓纪律

只顺大趋势方向加仓，绝不逆势补仓；突破或拉回须放量确认；单次加仓风险 ≤ 2%，总仓位风险 ≤ 20%，加仓量一般不超过底仓。

3

加仓后管理

加仓后立即上移止损至保本；沿趋势线 / 均线移动跟踪；出现反向 123 / 2B 信号全部离场；跌破形态边界即止损，绝不扛单。

Workflow

系统执行流程

四道关卡，环环相扣。任何一关不满足，都不进入下一关，宁可错过，不可做错。

1

环境判定 —— 双突破定方向

画出长期趋势线与形态颈线，等待「双突破」确认大级别反转。

趋势线突破 + 颈线突破 + 放量 → 确定唯一可交易方向
2

信号触发 —— 123 为主、2B 为辅

在既定方向上等待 123 法则点 3 确认；若出现 2B 假突破陷阱，可提前或加重信号权重。

主信号 123 必现；2B 为增强项，二者共振 = 最优信号
3

入场与风控 —— 固定风险比例

依据止损距离倒推仓位，单笔风险锁定在账户 2% 以内。

仓位 = (账户 × 2%) ÷ (入场价 − 止损价)
4

持仓与离场 —— 让利润奔跑

首目标看前高 / 形态测算位；随后用移动止损沿趋势线跟踪，反向 123 / 2B 或跌破趋势线即离场。

截断亏损、让利润奔跑
